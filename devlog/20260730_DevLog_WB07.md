## 세부 작업 내역

### 1. `list_all()` 캐싱 — `services/project_manager.py`

**문제**: Streamlit은 매 사용자 인터랙션마다 전체 스크립트를 재실행한다. `list_all_projects()`는 매 재실행마다 `data/projects/` 디렉터리의 모든 JSON 파일을 열고 파싱하여 불필요한 I/O가 반복됐다.

**해결**: `ProjectManager`에 인스턴스 레벨 시간 기반 캐시를 추가했다. `@st.cache_data`를 사용하지 않는 이유: Repository 레이어에 Streamlit 의존성을 주입하지 않기 위해 순수 Python `time` 모듈로 구현했다.

```python
class ProjectManager:
    _CACHE_TTL: float = 60.0  # 캐시 유효 시간 (초)

    def __init__(self, repository: ProjectRepository) -> None:
        ...
        self._project_list_cache: Dict[str, str] = {}
        self._cache_timestamp: float = 0.0

    def _invalidate_project_cache(self) -> None:
        """캐시를 즉시 만료시켜 다음 접근 시 강제 갱신."""
        self._cache_timestamp = 0.0

    def list_all_projects(self) -> Dict[str, str]:
        now = time.time()
        if now - self._cache_timestamp > self._CACHE_TTL:
            # Cache miss: 파일 시스템 실제 파싱
            self._project_list_cache = self.repository.list_all()
            self._cache_timestamp = now
        else:
            # Cache hit: 메모리 반환
            pass
        return self._project_list_cache
```

**캐시 무효화 전략**: 데이터 변경 이벤트(저장, 삭제) 발생 즉시 `_cache_timestamp = 0.0`으로 리셋. 다음 `list_all_projects()` 호출 시 항상 파일 시스템을 읽는다.

```python
def save_project(self, project: Project) -> bool:
    ...
    result = self.repository.save(project)
    self._invalidate_project_cache()  # 저장 후 즉시 무효화
    return result

def delete_project(self, project_id: str) -> bool:
    ...
    result = self.repository.delete(project_id)
    self._invalidate_project_cache()  # 삭제 후 즉시 무효화
    return result
```

**효과**: `@st.cache_resource`로 `ProjectManager`가 싱글턴이므로 캐시는 프로세스 전체에 걸쳐 유지된다. 60초 TTL 내에 사이드바가 재렌더링되어도 JSON 파일 파싱은 발생하지 않는다.
