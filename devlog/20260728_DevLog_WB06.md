## 세부 작업 내역

### 1. `Connection` dataclass 도입

**문제**: 연결 관계가 `Dict[str, Any]` 타입으로 저장되어 다음 문제가 존재했습니다.

- 키 이름 오타가 런타임까지 감지 불가 (mypy 검출 불가)
- `conn.get('from_element', '')` 형식의 방어적 접근 코드 반복
- `project.connections: List[Dict[str, Any]]` 타입 선언의 정보량 부재

**해결**: `models/project.py`에 `Connection` dataclass를 추가하고 모든 관련 코드를 교체했습니다.

#### `models/project.py` — `Connection` dataclass 추가

```python
@dataclass
class Connection:
    """Typed representation of a relationship between two world elements."""
    from_element: str = ""
    to_element: str = ""
    connection_type: str = "influences"
    description: str = ""
```

#### `Project` 클래스 변경

```python
# 변경 전
connections: List[Dict[str, Any]] = field(default_factory=list)

def add_connection(self, connection: Dict[str, Any]) -> None: ...
```

```python
# 변경 후
connections: List[Connection] = field(default_factory=list)

def add_connection(self, connection: Connection) -> None: ...
```

#### `from_dict()` — 기존 JSON 파일 역호환 처리

```python
# 기존 JSON 파일(dict)과 메모리 내 Connection 객체를 모두 처리
raw_connections = data.get("connections", [])
connections = [
    Connection(**c) if isinstance(c, dict) else c
    for c in raw_connections
]
```

`to_dict()`는 `asdict()` 재귀 변환을 사용하므로 별도 수정 없이 올바르게 직렬화됩니다.

#### `components/connections.py` — dict 접근 → attribute 접근

```python
# 변경 전
from_elem = conn.get('from_element', '')
conn_type = conn.get('connection_type', 'influences')
desc = conn.get('description', '설명 없음')

# 변경 후
from_elem = conn.from_element
conn_type = conn.connection_type
desc = conn.description or '설명 없음'
```

`render_connection_form()`에서 `Connection` 객체를 생성하도록 변경:

```python
# 변경 전
new_connection = {
    'from_element': from_element,
    'to_element': to_element,
    'connection_type': connection_type,
    'description': description.strip()
}
on_add(new_connection)

# 변경 후
new_connection = Connection(
    from_element=from_element,
    to_element=to_element,
    connection_type=connection_type,
    description=description.strip()
)
on_add(new_connection)
```

#### `app.py` — 타입 힌트 및 속성 접근 수정

```python
# 변경 전
def add_connection(connection: dict) -> None:
    logger.debug(f"... {connection.get('from_element')} -> {connection.get('to_element')}")

# 변경 후
def add_connection(connection: Connection) -> None:
    logger.debug(f"... {connection.from_element} -> {connection.to_element}")
```

#### `tests/conftest.py`, `tests/test_models.py` — Connection 객체 사용

```python
# 변경 전 (conftest.py)
project.connections = [
    {'from_element': 'space', 'to_element': 'culture', ...}
]

# 변경 후
project.connections = [
    Connection(from_element='space', to_element='culture', ...)
]
```

### 2. `ELEMENT_LABELS` constants.py 통합

**문제**: 동일한 12요소 라벨 매핑이 3곳에 중복 정의되어 있었습니다.

| 파일 | 형태 | 범위 |
|------|------|------|
| `components/connections.py` | 모듈 레벨 `ELEMENT_LABELS` dict | 모듈 전체 |
| `components/dashboard.py` | 함수 내 `element_labels` 로컬 변수 | `render_element_progress()` 내부 |
| `components/element_form.py` | 함수 내 `element_labels` 로컬 변수 (주석: "dashboard.py와 동일") | `render_element_form()` 내부 |

**해결**: `constants.py`에 단일 출처를 추가하고, 세 컴포넌트가 import하도록 변경했습니다.

#### `constants.py` — 추가

```python
ELEMENT_LABELS: Final[Dict[str, str]] = {
    'space': '🌌 공간',
    'time': '⏰ 시간',
    'creatures': '👥 생물',
    'nature': '🌿 자연',
    'culture': '🎭 문화',
    'language': '🗣️ 언어',
    'mythology': '⚡ 신화',
    'philosophy': '💭 철학',
    'rules': '⚖️ 규칙',
    'economy': '💰 경제',
    'politics': '🏛️ 정치',
    'energy': '✨ 에너지',
}
```

#### 각 컴포넌트 변경

```python
# connections.py — 기존 모듈 레벨 dict 제거 후 import

# dashboard.py — 로컬 변수 제거 후 import
from constants import ALL_ELEMENT_NAMES, ELEMENT_LABELS

# element_form.py — 로컬 변수 제거 후 import
from constants import ALL_ELEMENT_NAMES, ELEMENT_LABELS
```
