## 세부 작업 내역

### 1. `@st.cache_resource` 적용 (Issue ③)

**문제**: Streamlit은 사용자 인터랙션마다 전체 스크립트를 재실행합니다. 모듈 레벨에 작성된 서비스 초기화 코드가 매 재실행마다 실행되어 불필요한 객체 생성이 반복됐습니다.

```python
# 개선 전 — 매 재실행마다 실행됨
repository = JsonProjectRepository(storage_dir=DEFAULT_STORAGE_DIR)
project_manager = ProjectManager(repository=repository)
logger.info("WorldBuilder application initialized")
```

```python
# 개선 후 — 프로세스 당 최초 1회만 실행됨
@st.cache_resource
def _init_project_manager() -> ProjectManager:
    repo = JsonProjectRepository(storage_dir=DEFAULT_STORAGE_DIR)
    pm = ProjectManager(repository=repo)
    logger.info("WorldBuilder application initialized")
    return pm

project_manager = _init_project_manager()
```

**효과**: `@st.cache_resource`는 반환된 인스턴스를 프로세스 수명 동안 재사용합니다. `repository`, `project_manager` 모두 싱글턴으로 동작하며 초기화 로그도 최초 1회만 출력됩니다.

### 2. 서비스 레이어 우회 제거 (Issue ①)

**문제**: `app.py`의 콜백 함수 4개가 `ProjectManager`를 통하지 않고 `Project` 모델을 직접 조작했습니다.

```python
# 개선 전 — 서비스 레이어 우회, 캡슐화 위반
def update_element(element_name, description):
    project.update_element(element_name, description)   # 모델 직접 호출
    project.update_completion_rate()                    # 중복 책임

def update_rules(natural, social, religious):
    project.elements.rules.natural = natural            # 3단계 깊이 직접 접근
    project.elements.rules.social = social
    project.elements.rules.religious = religious
    project.update_completion_rate()
    project._update_timestamp()                         # private 메서드 외부 호출

def update_concept_logline(logline):
    project.concept.logline = logline                   # 속성 직접 수정
    project._update_timestamp()

def update_concept_keywords(keywords):
    project.concept.keywords = keywords
    project._update_timestamp()
```

**해결**: `ProjectManager`에 3개의 새 메서드를 추가하고, 모든 콜백이 서비스 레이어를 경유하도록 수정했습니다.

#### 2.1 `services/project_manager.py` — 신규 메서드 3개

```python
def update_project_logline(self, project: Project, logline: str) -> Project:
    """Update project logline."""
    logger.info(f"Updating logline for project: {project.project_id}")
    project.update_logline(logline)
    return project

def update_project_keywords(self, project: Project, keywords: List[str]) -> Project:
    """Update project keywords."""
    logger.info(...)
    project.update_keywords(keywords)
    return project

def update_project_rules(
    self, project: Project,
    natural: List[str], social: List[str], religious: List[str]
) -> Project:
    """Update project rules and recalculate completion rate."""
    logger.info(f"Updating rules for project: {project.project_id}")
```

#### 2.2 `app.py` — 콜백 개선

```python

def update_element(element_name, description):
    project_manager.update_project_element(project, element_name, description)
```

기존에 존재하던 `update_project_element()`는 이미 서비스 레이어에 있었으나, `app.py`가 이를 사용하지 않고 직접 모델을 호출하고 있었습니다. 이번 수정으로 완전히 경유하도록 통일했습니다.

### 3. 캡슐화 위반 제거 (Issue ②)

**문제**: `project._update_timestamp()`는 `_` prefix로 내부 전용임을 표시한 private 메서드입니다. `app.py`에서 이를 4회 직접 호출하고 있었으며, `add_connection`/`delete_connection`에서도 동일한 문제가 있었습니다.

**해결**: `Project` 모델에 5개의 public 메서드를 추가하여 모든 상태 변경이 모델 내부에서 `_update_timestamp()`를 호출하도록 캡슐화했습니다.

#### 3.1 `models/project.py` — 신규 메서드 5개

```python
def update_logline(self, logline: str) -> None:
    """Update project logline."""
    self.concept.logline = logline
    self._update_timestamp()

def update_keywords(self, keywords: List[str]) -> None:
    """Update project keywords."""
    self.concept.keywords = keywords
    self._update_timestamp()

def update_rules(
    self,
    natural: List[str],
    social: List[str],
    religious: List[str]
) -> None:
    """Update rules element."""
    self.elements.rules.natural = natural
    self.elements.rules.social = social
    self.elements.rules.religious = religious
    self._update_timestamp()

def add_connection(self, connection: Dict[str, Any]) -> None:
    """Append a new connection and update timestamp."""
    self.connections.append(connection)
    self._update_timestamp()

def remove_connection(self, index: int) -> None:
    """Remove a connection by index and update timestamp."""
    self.connections.pop(index)
    self._update_timestamp()
```

#### 3.2 `app.py` — 연결 관련 콜백 개선

`add_connection`/`delete_connection`도 모델 메서드를 사용하도록 변경했으며, 이 과정에서 파생된 두 가지 추가 개선이 이뤄졌습니다.

**미사용 변수 제거**:
```python
# 개선 전
deleted = project.connections.pop(index)  # `deleted` 미사용

# 개선 후 — remove_connection() 위임으로 자연 해소
project.remove_connection(index)
```

**예외 처리 개선**:
```python
# 개선 전 — 명시적 범위 체크 후 분기
if 0 <= index < len(project.connections):
    project.connections.pop(index)
else:
    st.error(f"잘못된 연결 인덱스: {index}")

# 개선 후 — list.pop()의 IndexError를 타입별로 포착
try:
    project.remove_connection(index)
except IndexError:
    st.error(f"잘못된 연결 인덱스: {index}")
```
